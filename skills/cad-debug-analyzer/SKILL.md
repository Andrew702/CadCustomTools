# CadCustomTools Debug Log Analyzer

Use this skill to audit runtime JSONL debug logs generated by the four ZWCAD AutoLISP tools and spot runtime errors, silent failures, or illogical behavior.

## Log File Locations

Each tool writes daily JSONL files (one JSON object per line) inside its own gitignored `logs/` folder (falling back to ZWCAD `TEMPPREFIX` only if `<Tool>/logs/` is unwritable):

| Tool | Log Glob | Debug Toggle Command |
| --- | --- | --- |
| `HvacRoom` | `HvacRoom/logs/hvacroom_YYYYMMDD.jsonl` | `RTDEBUG` |
| `FireSprinkler` | `FireSprinkler/logs/firesprinkler_YYYYMMDD.jsonl` | `FFDEBUG` |
| `SmartFilter` | `SmartFilter/logs/smartfilter_YYYYMMDD.jsonl` | `SFDEBUG` |
| `SelectionHistory` | `SelectionHistory/logs/selectionhistory_YYYYMMDD.jsonl` | `SHDEBUG` |

## Unified JSONL Event Envelope

```json
{
  "ts": "2026-11-26T00:15:30",
  "ms": 14829310,
  "tool": "HvacRoom",
  "run_id": "rt-20261126-001530-1",
  "seq": 1,
  "dwg": "Level1.dwg",
  "cmd": "HVACROOM",
  "level": "INFO",
  "event": "RUN_START",
  "data": {}
}
```

## Step 1: Universal Structural & Error Checks (All Tools)

For every JSONL file being audited:
1. **Valid JSON**: Flag any line that fails `json.loads()` (possible truncation or escaping bug).
2. **Error Events**: Flag any line where `level == "ERROR"` or `event` is `"ERROR"`, `"DIALOG_ERROR"`, `"EXPORT_ERROR"`, `"REACTOR_ERROR"`, or `"MODULE_LOAD"` with `data.ok == false`.
3. **Run Lifecycle Integrity**: Group non-reactor events by `run_id` (skip `cmd == "REACTOR"` and `*-init-*` module-load ids).
   - Every `RUN_START` must have a matching `RUN_END` or `ERROR` with the same `run_id`. An unclosed `RUN_START` indicates a hard crash or unhandled abort.
   - `seq` within a `run_id` must be strictly increasing (`1, 2, 3, ...`).
   - `elapsed_ms` on `RUN_END` / `ERROR` must be `>= 0`.

## Step 2: Tool-Specific Logical Invariant Checks

### HvacRoom (`tool == "HvacRoom"`)

- **`TAG_PLACED`**:
  1. `mtext_handle` must be a non-empty string (null means `entmake` failed).
  2. Recompute expected area:
     - `biased = raw_area * factor + bias`
     - `mult = 10 ** prec`
     - `"up"`: `ceil(biased * mult - 1e-9) / mult`
     - `"down"`: `floor(biased * mult + 1e-9) / mult`
     - `"nearest"`: `int(biased * mult + 0.5 + 1e-9) / mult` (for `>= 0`; symmetric for `< 0`)
     - Flag if `abs(expected_area - area_m2) > 1e-6`.
  3. Flag if `area_m2 <= 0`.
  4. If `chw_en == true`:
     - Flag if `ton_factor <= 0`.
     - Recompute `expected_gpm = round_nearest((area_m2 / ton_factor) * 2.4, prec)`; flag if `abs(expected_gpm - chw_gpm) > 1e-6`.
  5. If `pipe_en == true`:
     - Flag if `chw_en != true` (pipe sizing requires CHW enabled) or `pipe_size == ""`.
     - Verify `pipe_size` matches `EDRC-STD-H-PD-001` table at `max(foundIdx, pipe_min_idx)`.
  6. Counter consistency: `num_after == num_before + 1`.
- **`TAG_UNDONE`**:
  - If `num_before > 0`, `num_after` must equal `num_before - 1`.
- **`EXPORT_COMPLETE`**:
  - `parsed_rows + skipped_rows == entity_count`.
  - Flag if `skipped_rows > 0` (corrupted/legacy XDATA).

### FireSprinkler (`tool == "FireSprinkler"`)

- **`TAG_PLACED`**:
  1. `mtext_handle` must be non-empty.
  2. Recompute `area_m2` using the same area pipeline as `HvacRoom`; flag if `abs(expected_area - area_m2) > 1e-6`.
  3. Flag if `cov_area <= 0` or `area_m2 <= 0`.
  4. Recompute `expected_spr = max(1, math.ceil(area_m2 / cov_area - 1e-9))` for `area_m2 > 0`; flag if `sprinklers != expected_spr`.
  5. Counter consistency: `num_after == num_before + 1`.
- **`APPEND_ITEM`**:
  - When `updated == true`, verify `sprinklers == max(1, math.ceil(area_m2 / cov_area - 1e-9))`.
  - Flag high rates of `updated == false` (`source == "NONE"`).
- **`APPEND_COMPLETE`**:
  - `updated + skipped == selected_count`.
- **`EXPORT_COMPLETE`**:
  - `parsed_rows + skipped_rows == entity_count`.

### SmartFilter (`tool == "SmartFilter"`)

- **`GROUPS_BUILT`**:
  - `sum_group_counts == total_count` and `sum_layer_counts == total_count`. Any discrepancy means entities were lost or double-counted during bucketing.
- **`FILTER_APPLIED`**:
  - `0 <= selected_count <= total_count`.
  - Flag warning if `selected_count > 0` and `pickfirst_sysvar == 0` (grips will not persist).

### SelectionHistory (`tool == "SelectionHistory"`)

- **All events with `history_len`**:
  - `0 <= history_len <= max_slots` (default `5`).
- **`HISTORY_PUSH`**:
  - `count > 0`.
  - `history_len_after == min(max_slots, history_len_before + 1)`.
- **`RECALL_SLOT`**:
  - When `outcome` is `"ok"` or `"all_erased"`: `live_count + erased_count == orig_count`.
  - When `outcome == "ok"`: `live_count > 0`.
  - When `outcome == "ok"` and `for_command == false` and `pickfirst_sysvar == 0`: flag environment warning.
- **`REACTOR_ERROR`**:
  - Always flag immediately with `callback` and `message`.

## Step 3: Reporting Format

When reporting findings to the user, group by tool and `run_id`:
- **Summary**: Total files scanned, total runs, total errors/warnings/anomalies.
- **Anomalies Table**: `Tool | File:Line | Run ID | Event | Severity | Details`
- **Root-Cause Hints**: Cross-reference the relevant tool skill (`hvac-room`, `fire-sprinkler`, `smart-filter`, or `selection-history`) to pinpoint the exact `.lsp` module and function responsible.
